## 🔴 2. Calif says it built a public Apple M5 kernel exploit with help from Anthropic’s Mythos model
**Category:** AI / Cybersecurity
**Impact:** High

**Why it matters:** This is an early public sign that advanced AI security models may materially speed up exploit research against even heavily hardened modern systems.

**What to know:** Calif said it developed the first public macOS kernel memory corruption exploit on Apple M5 hardware and credited Mythos Preview with helping identify bugs and support exploit development. The important angle is not only the Apple security claim, but the implication that Anthropic’s Claude Mythos Preview may already be useful in serious offensive security research. Readers should still treat parts of this carefully: Calif has not yet published the full technical report, and some of the strongest claims remain based on the company’s own account until Apple patches and outside researchers can review more detail.

**Source:** [Calif - First public macOS kernel memory corruption exploit on Apple M5](https://blog.calif.io/p/first-public-kernel-memory-corruption), published May 14, 2026

**Quick Takeaway:** The practical AI race is increasingly about who becomes the control layer for everyday work, and which frontier models can change the pace of high-stakes security research.
