# Daily Tech Digest - November 1, 2026
> **Today's signal:** Two security reports illustrate the difference between a security claim and a verified protection.

## 🔴 1. Research questions fingerprint USB encryption
A researcher found that a Lenovo ThinkPlus FU100 fingerprint drive stored data on an unencrypted SD card, despite encryption claims, according to Tom’s Hardware. The report also describes a Lenovo remedy for affected products.

**Why it matters:** Biometric access control alone does not establish that stored data is encrypted.

**Source:** [Tom’s Hardware - Fingerprint drive stored data unencrypted](https://www.tomshardware.com/tech-industry/cyber-security/lenovo-fingerprint-usb-stick-sold-as-aes-256-encrypted-had-a-plain-sd-card-inside-ai-assisted-follow-up-finds-a-backdoor-and-hardcoded-keys-in-other-secure-usb-products), November 1, 2026

## 🟡 2. Trigger.dev discloses exposed environment variables
Trigger.dev disclosed unauthorized access to environment variables for a subset of organizations and said the exploit had been blocked. It notified affected account owners.

**Why it matters:** Environment variables can contain credentials, so affected organizations need to follow the provider’s mitigation instructions and rotate exposed secrets.

**Source:** [Trigger.dev - Security disclosure](https://trigger.dev/blog/security-incident-nov-2026), November 1, 2026

**Quick Takeaway:** Two security reports illustrate the difference between a security claim and a verified protection.
